# ✍️ SchriftBot

SchriftBot ist ein Browser-MVP, der Text in eine handschriftähnliche Darstellung umwandelt und als SVG/PNG exportiert.

## Aktueller Stand

- 📱 Tablet- und Smartphone-freundliche Oberfläche
- 📝 Textfeld für eingefügten Text
- 🎚️ Größe, Zeilenabstand und natürliche Variation
- ✂️ Einzelne Buchstaben im Ergebnis anklicken und löschen
- 📦 SVG-Export mit einzelnen Glyphen als Elementen
- 🖼️ PNG-Export
- 📄 Druckbare Handschrift-Vorlage als SVG

## Wichtiger Hinweis

Die erste Version nutzt die geladene Handschriftprobe noch nicht zur automatischen Glyphen-Erkennung. Das ist der nächste technische Schritt: Die Buchstaben aus einer standardisierten Probe werden erkannt, ausgeschnitten und anschließend als individuelle Glyphen wiederverwendet.

## Lokal testen

Einfach `index.html` im Browser öffnen. Für GitHub Pages ist das Projekt bereits als statische Website aufgebaut.

## Ziel

Eine Handschriftprobe auf dem Galaxy Tab S7 FE aufnehmen, Text einfügen und ein möglichst natürliches Ergebnis erzeugen, das sich vor dem Import in Samsung Notes noch bearbeiten lässt.
